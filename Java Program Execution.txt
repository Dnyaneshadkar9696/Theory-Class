1. Source Code ( .java )


Definition
-> Source code is the human-readable Java program written by developers using the Java syntax.

Where it is written?
In a .java file.

Example
class Test {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}

Characteristics

Written by the programmer.
Understandable to humans.
Cannot be understood directly by the machine.
Needs to be compiled.





âœ… 2. Byte Code ( .class )

Definition

-> Byte code is a platform-independent, intermediate code generated by the Java compiler (javac).

Where is it stored?
In a .class file.

Characteristics
Not readable by humans.
Understandable by the Java Virtual Machine (JVM).
Same byte code can run on any operating system (Windows, Linux, Mac).
Provides Write Once, Run Anywhere (WORA) feature.


How it is generated?
javac Test.java

This creates:
Test.class




 3. Native Code (Machine Code)

Definition
-> Native code is the OS-dependent machine code generated by the JIT (Just-In-Time) Compiler inside the JVM at runtime.

Characteristics
This is the actual code executed by the CPU.
Fully machine-dependent (different for Windows, Linux, Mac).
Converts frequently used byte code into machine code for performance.
