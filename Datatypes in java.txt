
Data Types in java :

Data types define what kind of data a variable can store in Java.
Java is a strongly typed language, which means you must declare the data type before using any variable.

Example:
int age = 25;



Types of Data Types in Java : 

Java data types are divided into two major categories:

A. Primitive Data Types
(8 data types provided by Java)

B. Non-Primitive Data Types
(Classes, Arrays, Interfaces, Strings, etc.)






Difference Between Primitive & Non-Primitive Data Types

Primitive              	Non-Primitive
8 fixed data types	Unlimited user-defined
Stored in Stack	        Stored in Heap
Stores value directly	Stores reference/address
Fast	                Slower
Defined by Java  	Created by user
